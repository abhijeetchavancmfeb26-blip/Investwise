Project Title

InvestWise – Personalized Investment Management Platform

Project Description

InvestWise is a full-stack web application that helps users plan finances, assess investment risk, receive personalized investment recommendations, track portfolios, and improve financial literacy. The platform also offers a Premium Subscription integrated with a secure Razorpay/Stripe payment gateway, providing advanced portfolio analytics, premium insights, downloadable reports, and exclusive learning resources. An Admin Portal enables management of users, investments, subscriptions, payments, and platform analytics.
